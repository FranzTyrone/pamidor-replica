PAMIDOR DESIGN — STATIC REPLICA

15 pages, with locally bundled imagery, fonts, styles, videos, and interactive client scripts.
Reference: https://pamidordesign.co/

RUN LOCALLY
Install Python 3, open a terminal in this folder, and run:
  python -m http.server 4173 --bind 127.0.0.1 --directory dist
Then open http://127.0.0.1:4173/
Do not open index.html directly: the site uses root-relative asset URLs.

EDIT
Page markup is in dist/index.html and dist/<route>/index.html.
Styles and public client bundles are in dist/_next/static/immutable/.
The static navigation and email-draft adapter is dist/replica.js.
Assets are bundled under dist/_img, images, videos, icons, and logos.

SCOPE AND LIMITS
This is a static replica of the public website, not the original development repository.
It retains original branding and content. The original private server, CMS, payment
credentials, inbox delivery, and subscription service are not included.
Contact and subscription forms prepare email drafts; they never send automatically.
Product availability and disabled controls match the captured storefront.
The reference's /videos/skillset-3d.mp4 is unavailable (404); its still imagery is retained.
Original third-party profile links remain external. Analytics are disabled.
